# The Dev MCP update procedure

When the operator says "run the update procedure", follow this procedure step by step. It performs the machine steps itself, hands the operator every step only a person can do (the bundle download, every edit under `~/.kiro/settings/`, the server restart, the browser sign-in, and approvals), and stops at the phase boundary.
